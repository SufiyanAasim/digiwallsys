**Status:** Release

## 📖 Overview

**Marina** gives the web build its own layout instead of stretching the mobile screen
stack across a desktop viewport: a persistent glass sidebar, a centered content column,
and web-only navigation state, all on the same Ember Glass tokens as Lantern.

## 🎯 Objectives

- Give the web client a dashboard-shaped layout distinct from the mobile stack.
- Add persistent navigation that doesn't remount the app on every route change.
- Surface the signed-in user, role, and quick navigation without a native header.
- Keep exactly one codebase for mobile and web.

## ✨ Production Scope & Enhancements

### 🖥️ Web dashboard shell

- `components/web/Sidebar.js`: persistent glass sidebar with profile card, role-aware
  navigation (including Admin), and Credits/Logout footer.
- `App.js` rewritten around a stable navigation tree: a `NavigationContainerRef` tracks
  the active route so the sidebar can appear/disappear without remounting the navigator.
- Centered, max-width content column so pages don't stretch full-bleed on wide screens.
- Native mobile builds are unaffected — the sidebar only renders when `Platform.OS === 'web'`.

## 🏛️ Architecture Progress

Marina is additive to the existing single-stack navigator; native builds keep their
existing header-based navigation untouched.

## 💻 Compatibility

Expo Web · Metro bundler · React Navigation 7 (JS stack on web)
