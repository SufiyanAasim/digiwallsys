# 🌊 digiwallsys — v1.9.0

> Codename: *Crest* - Aurora Glass interface, responsive refinement, and renewed brand assets

---

## 📖 Overview

**Crest** introduces Aurora Glass across the shared Expo web and native
clients. Deep teal foundations, mint/cyan energy, clearer hierarchy, and
responsive glass surfaces replace the active Ember Glass presentation while
the earlier artwork remains preserved as versioned history.

## 🎯 Objectives

- Establish one accessible Aurora Glass palette across every client surface.
- Improve hierarchy and interactive feedback without changing route behavior.
- Keep desktop, mobile-web, Android, and iOS geometry stable during animation.
- Give sidebar, status, balance, cards, footer, scrollbars, and logos one visual
  language.
- Preserve reproducible current and historical brand assets.
- Add secure self-service profile, verified-email, and password controls.

## ✨ Feature groups

### 🌌 Aurora Glass system

- Deep teal canvas with translucent green-teal surfaces.
- Mint-to-cyan primary gradients and supporting chart series.
- High-contrast ink, muted copy, borders, focus states, and semantic colors.
- Backdrop blur, subtle elevation, and controlled ambient movement.
- Matching dark and light palettes using the same brand identity.

### 🧭 Refined navigation and status

- Aurora sidebar wash, active gradient rail, grouped workspace navigation, and
  live-service status.
- Compact authenticated mobile-web header below 900px, with Home, Credits,
  theme, logout, and dynamic-initials controls.
- Dashboard ledger status, verified-balance treatment, responsive action grid,
  and clearer zero-balance guidance.
- Branded scrollbar, public footer, route transitions, hover states, and press
  feedback.
- Reduced-motion support remains authoritative across web and native.

### 🎨 Brand assets

- New scalable Aurora Glass monogram and wordmark.
- New Android/iOS icon, adaptive foreground, web favicon, and repository
  marketing artwork.
- Deterministic `npm run brand:generate` asset workflow.
- Prior Ember Glass artwork retained under explicit `ember-glass` paths.

### 👤 Profile and credentials

- Edit the display name and see dashboard/sidebar initials update immediately.
- Change email only after confirming the current password; the new address
  becomes active but must be verified before the next sign-in.
- Change password after current-password verification and revoke every saved
  refresh session across web and mobile.
- Audit profile and password changes without logging credentials or personal
  field values.

### 🤝 Creator contact

- Expanded creator profile with project ownership, engineering scope, and
  capability highlights.
- Accessible GitHub and email actions open the public profile or the device's
  default mail application with the contact address prefilled.

## 🏛️ Architecture progress

The redesign remains token-driven: screens consume shared theme colors and
layout helpers instead of release-specific styling. Motion continues to use
opacity and transforms only, avoiding reflow and preserving touch geometry.
Generated PNG assets and hand-authored SVGs share the same color constants.

## 💻 Compatibility

Expo SDK 57 · React Native 0.86 · React Native Web 0.21 · Android · iOS ·
modern Chromium, Firefox, and Safari browsers
