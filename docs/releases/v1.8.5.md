# 🌊 digiwallsys — v1.8.5

> Codename: *Trench* - Coordinated motion, transfer-ready demo users, and container delivery

---

## 📖 Overview

**Trench** adds a shared motion language across the Expo web and native clients,
repeatable acceptance accounts for two-way transfer testing, and a publishable
GitHub Container Registry image.

## 🎯 Objectives

- Make navigation and controls feel responsive without changing layout geometry.
- Keep motion accessible through the operating system's reduced-motion setting.
- Provision verified demo users without committing plaintext passwords.
- Fund demo wallets through balanced ledger journals rather than direct balances.
- Publish the production API/worker image as an OCI package.

## ✨ Feature groups

### 🎞️ Coordinated interaction

- Route-level fade and lift transitions across public and protected screens.
- Spring-free, deterministic hover and press feedback on shared controls.
- Long-duration ambient movement on web and native.
- Staggered Credits content and animated login-state entry.
- Existing landing-page cards and glows now honor reduced-motion preferences.

### 👥 Transfer acceptance accounts

- Idempotent `npm run demo:seed` workflow for two verified member accounts.
- Passwords supplied only through one-time environment variables.
- Opening balances posted through `demo_funding` journals against provider
  clearing, keeping wallet reconciliation balanced.
- Users appear in each other's recipient list and can transfer in both directions.

### 📦 GitHub Packages

- CI builds and publishes `ghcr.io/sufiyanaasim/digiwallsys`.
- Default-branch, version-tag, and immutable commit-SHA image tags.
- OCI source, description, and licence metadata.
- GitHub Actions cache reuse for repeatable image builds.

## 🔧 Changes

- Public version: `1.8.5`.
- Android version code: `11`.
- iOS build number: `6`.
- Added shared `MotionProvider`, `MotionScreen`, and `MotionSection` primitives.
- Added secure demo-user provisioning and environment templates.
- Aligned the historical `v1.3.5` codename consistently as Shoal.

## 🏛️ Architecture progress

Motion uses transforms and opacity only, so animation does not reflow the
dashboard grid or alter touch targets. Demo funding reuses the immutable ledger
service and clearing-account model used by verified provider callbacks.

PostgreSQL 14+ · OCI/Docker
