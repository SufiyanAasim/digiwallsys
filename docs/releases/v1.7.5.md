# 🌊 digiwallsys — v1.7.5

> Codename: *Convoy* - Savings, budgets, calendars, tagging, and statements

---

## 📖 Overview

**Convoy** converges several financial-product features into one release: savings
goals with round-up, budget categories, a payment calendar, transaction tagging, a
PDF statement export, and user-facing fraud alerts. Multi-currency wallets and
shared/family wallets were deliberately scoped out to their own release (`v1.8.0`,
"Estuary") since they touch core ledger and auth logic directly.

## 🎯 Objectives

- Let users earmark part of their balance toward a goal, optionally funded by
  rounding up direct transfers — without introducing a second real-money ledger.
- Give spending a category, and a monthly limit to track it against.
- Visualize existing scheduled transfers on a calendar instead of a flat list.
- Let users export a readable PDF statement, not just a CSV.
- Surface the fraud engine's findings to the affected user, not just admins.

## ✨ Production Scope & Enhancements

### 🏦 Savings goals

- `savings_goals` table: target/current amount tracked as an earmark against the
  existing single wallet balance — no new money-movement path, no schema change to
  `wallet` or `transactions`.
- Manual contribute/withdraw, validated against the balance not already earmarked
  by other goals.
- Optional round-up: after a direct transfer, the rounded-up remainder is credited
  to at most one round-up-enabled goal per user (enforced by a partial unique index),
  within the transfer transaction, capped by the same-currency unearmarked balance.

### 📊 Budget categories

- `budget_categories` table plus a new `transactions.category` column.
- Spend-per-category computed live against the current calendar month.
- Categories are selectable when sending money, and any past transaction you sent
  can be re-tagged from Transaction history.

### 🗓️ Payment calendar

- New calendar view over the existing `/api/schedules` data — no backend change.

### 📄 Statement export

- `GET /api/transactions/statement`: a formatted PDF (via `pdfkit`) alongside the
  existing CSV export, with totals received/sent/net for the selected range.

### 🛡️ User-facing security alerts

- `GET /api/security/alerts`: the existing admin-only `fraud_events` table,
  surfaced to the affected user in plain language, with technical fields stripped.

### 🎨 Also in this release

- Real light/dark theme toggle (previously an unused `ThemeContext`), persisted via
  AsyncStorage, with a themed `Switch` so toggles render on-brand rather than with
  browser-default colors.
- Frosted-glass "d/i" monogram app icon and adaptive-icon assets, replacing the
  wallet-icon artwork used since v1.5.5.

## 🏛️ Architecture Progress

Every new table is additive; the double-entry ledger, `wallet`, and `transactions`
core columns are untouched. Round-up earmarks are currency-scoped and commit
atomically with the transfer that created them.

## 💻 Compatibility

iOS · Android · Web · requires running `config/migrations/003_convoy_features.sql`
against the target database before deploying this version's API.
