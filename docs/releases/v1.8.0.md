## 📖 Overview

**Convoy** is reserved for the two financial features too consequential to bundle
into Estuary: multi-currency wallets with FX conversion, and shared/family wallets
with per-member spending limits. Both touch core ledger and authorization logic
directly and need their own dedicated scoping, migration, and testing pass.

## 🎯 Candidate scope

- Multi-currency wallets: hold balances in more than one currency, with FX
  conversion on transfer between differing-currency wallets (`transferService.js`
  currently rejects cross-currency transfers outright).
- Shared/family wallets: multiple users attached to one wallet with individual
  spending limits and permissions, distinct from the existing single-owner model.

## 🏛️ Architecture Progress

Not started. Depends on an explicit scope decision before any schema or ledger
logic changes.
