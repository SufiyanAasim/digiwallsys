# 🌊 digiwallsys — v1.6.0

> Codename: *Lantern* - Mobile Ember Glass design system and brand identity

---

## 📖 Overview

**Lantern** replaces the mobile client's visual identity with "Ember Glass" — a dark,
glass-surfaced design language built around the existing digiwallsys rose brand color,
plus a live in-app confirmation toast and a proper "d/i" monogram and gradient wordmark.

## 🎯 Objectives

- Redesign every mobile screen and control around a single glass design system.
- Replace ad hoc buttons with reusable glass-tile and gradient-button components.
- Add a non-blocking confirmation toast for sign-in and other account events.
- Replace the wallet-icon artwork with an original digiwallsys monogram and wordmark.
- Fix a header-theme crash that produced a white screen on every non-Home screen.

## ✨ Production Scope & Enhancements

### 🎨 Ember Glass design system

- New shared token set in `theme.js`: glass surfaces, borders, glow, and radii.
- `AmbientBackground`, `GradientButton`, `ActionTile`, and `ToastProvider` components.
- Reworked Home, Login, and all account/detail screens onto the shared system.

### 🔔 In-app notifications

- Post-login "Signed in successfully" toast, reusable for future confirmations.

### 🖋️ Brand identity

- `Logo` component: an overlapping "d"/"i" monogram badge, no external image asset.
- `Wordmark` component: gradient-filled "digiwallsys" text matching the Ember Glass palette.

### 🐛 Fixes

- Added the `fonts` theme object React Navigation v7 requires, fixing a crash in
  `HeaderTitle` that produced a white screen on every screen except Login and Home.

## 🏛️ Architecture Progress

Lantern is a visual and component-layer release — no API or ledger behavior changed.

## 💻 Compatibility

Expo SDK 53 · React Navigation 7 · iOS · Android · Web
