**Status:** Historical implementation milestone

## 📖 Overview

**Armada** added the deployment shape for a managed PostgreSQL database, a
containerized API, and an exported web dashboard, alongside dark-mode styling
and system credits. It does not claim that any former provider URL is still live.

## 🎯 Objectives

- Prepare PostgreSQL schema, triggers, and migrations for managed hosting.
- Prepare the Express API for containerized hosting.
- Export the Web Dashboard bundle with cross-platform session storage.
- Integrate sleek Dark Mode design system and system credits screen.
- Verify security, rate limits, CORS, and double-entry ledger stability end-to-end.

## ✨ Production Scope & Enhancements

### 🚢 Deployment support

- **Database**: PostgreSQL pool connectivity and versioned migrations.
- **Backend API**: reproducible container build and health endpoint.
- **Web Dashboard**: Expo Web export with cross-platform session persistence.
- **UI & Experience**: Native Dark Mode theme, inline error alert banners, and dedicated Credits Screen.

## 🏛️ Architecture Progress

Armada connected the application layers behind provider-neutral deployment
configuration. Current deployment state is documented only in the main README.
